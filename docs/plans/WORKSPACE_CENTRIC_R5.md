# R5：企业员工网页小助手

开始日期：2026-09-22。状态：实现与合成验收已完成；R6 企业目标环境待验。依据[总体设计](../OVERALL_DESIGN_ZH.md)和[已确定的 R5 范围](WORKSPACE_CENTRIC_REDESIGN_ZH.md#r5发布仅供企业员工使用的网页小助手)。

## 实施顺序

- [x] R5-1：核对原生渠道、真实员工会话及现有网关边界。原生渠道可由 Viewer 读取、Admin/Owner 管理，渠道令牌不能代替员工身份。
- [x] R5-2：接入原生渠道管理，过滤秘密字段，提供来源域名、启停、限流和嵌入信息。
- [x] R5-3：员工渠道请求适配与持久化会话绑定；授权、撤销、引用及限流回归。
- [x] R5-4：发布界面、独立网页/挂件、企业登录与原生聊天组件接入。
- [x] R5-5：隔离合成 API、迁移恢复、浏览器和工程验收；保存前后截图。
- [x] R5-6：更新设计、部署指南、路线图和验收报告；列明 R6 企业目标环境待验项。

## 固定边界

- 原生渠道和 Agent 仍由 WeKnora 管理。产品只保存员工渠道会话绑定、限流计数及适用审计，不存储渠道发布令牌。
- 问答使用真实员工 bearer 与渠道所在空间；每次检查员工、成员、渠道、Agent 和知识范围。原生匿名 embed 路由继续关闭。
- 独立网页通过产品来源的 iframe 展示，发布代码只含非秘密的空间和渠道 ID。企业登录使用第一方弹窗，员工访问令牌仅通过指定来源、指定窗口和随机握手值交给小助手，不交给宿主网页。
- 原生 OAuth 回调及开户继续复用 R2；iframe 不依赖第三方登录 Cookie。登录过期后重新认证，渠道关闭或员工撤销在新请求和流式重连时生效。
- 渠道会话与主站会话分别访问，不能去掉渠道路径绕过渠道撤销。图片、引用和附件同样经过员工渠道接口及会话范围检查。
- 保持上游源码干净。R5 的合成通过不代表真实企业 IdP、代理、模型或目标域名已通过 R6 验收。
- [R6 后的七项待办](POST_R6_FEATURE_BACKLOG_ZH.md)不并入此次交付；仅复用原生渠道已有配置。
