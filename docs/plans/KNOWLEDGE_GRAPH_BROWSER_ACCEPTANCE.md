# E-01 知识图谱浏览验收

日期：2026-10-08。用户明确要求提前实现 E-01，只读展示对 Owner、Admin、Contributor 可见。E-02 人工修订和其他后置功能维持独立待办。

## 实现及边界

- 知识库详情新增“知识图谱”；原 `graph` 页签仍为 Wiki 链接图。新页签使用 `knowledge-graph`，支持刷新恢复、搜索、关系筛选、缩放、拖动、实体/关系详情、一跳展开和原生文档预览。
- 产品 `graphview` 服务通过原生 `/auth/me`、知识库详情和文档详情校验真实会话、当前成员角色、空间及资源权限。Viewer、停用用户、非成员、机器 Key 和跨空间请求均拒绝。所有查询都使用原始员工/admin bearer 进行前置校验。
- 固定上游没有已入库实体图的公开读取接口；Wiki 图和初始化预览无法满足。采用产品侧 Neo4j 驱动只读适配器，未改上游或引入上游 `internal/**`。查询绑定已授权 KB 标签，两端及中心节点均有同一标签约束，查询文本固定，用户输入仅作为参数。直接读取仅覆盖固定 v0.8.0 `ENTITY<KB UUID>` / `kg` / `attributes` 结构；上游升级必须复验，未来原生公开接口可用时替换此适配器。
- 过滤异步清理期间仍残留的已删除或移出文档节点及关系。图谱属性和返回数量有上限，不返回数据库标签、凭据或任意属性；查询失败只返回稳定错误码。
- 无新增数据库表和迁移，无图谱写操作，无生产部署及历史验收记录修改。

## 本轮验证

证据见 [JSON 记录](evidence/graph-view-verification.json)。页面使用真实编译后的 Vue 应用及合成 API 响应；数据库测试使用独立临时 Neo4j 2025.10.1 容器。两者是分别验证，不标记为真实企业 OAuth/模型或生产联调通过。

| 验证 | 范围 |
|---|---|
| 网关无缓存测试 | `go test -count=1 ./...`，覆盖现有身份、模型、MCP、空间、助手回归及新增图谱用例 |
| 角色和资源隔离 | 三角色允许；Viewer、无成员、停用、API Key、伪造空间、无 KB 权限拒绝，且拒绝用例数据库调用计数为零；完整网关路径另验企业停用、开户未完成、旧接口 410 与写请求拒绝 |
| 生命周期 | 来源删除/移库过滤，角色降级后展开拒绝，图谱关闭不查库 |
| 真实 Neo4j | 有限加载、关系过滤、搜索、一跳展开、跨库节点/连线隔离、越界中心节点、参数化输入 |
| 前端 Node 24 | 单元测试、类型检查及生产构建；同名实体保持区分、累计上限、自环及双向关系 |
| 浏览器 | 变更前基线、三个角色入口及 Viewer 隐藏/跳转、详情、搜索、过滤、邻居展开、来源请求、深链接刷新、空/禁用/错误及重试、窄屏 |
| 工程 | 网关竞态检查、上游边界、设计文档和前端覆盖层检查 |
