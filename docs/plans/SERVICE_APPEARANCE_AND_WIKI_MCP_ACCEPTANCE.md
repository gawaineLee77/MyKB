# 全站外观、智能体图标与 Wiki MCP 验收

日期：2026-10-19。范围：产品网关、产品前端覆盖、产品迁移与合成测试。本文记录功能实现阶段的验证；随后完成的企业包验证见[2026-10-19 包验收](CURRENT_AMD64_UPGRADE_20261019.md)。企业部署、真实员工 OAuth/模型联调仍由目标环境验收。

## 实现范围

- 全站名称与 Logo 为运行时配置，仅安装记录指定的本地管理员可写；默认“小纳”，以后可改名。配置版本冲突保护、图片解码规范化、原子审计。
- 知识库来源筛选五项，其他来源仍在“全部来源”显示。
- 自定义智能体上传、预览、替换、移除图标；认证读取、空间和可见性隔离、短引用、并发配额。
- 新增只读 `wiki_search`、`wiki_read_page`，沿用 MCP 身份、API Key 范围、KB ACL、撤销、限流和审计。
- 000020–000021 产品表；上游源码及数据库不变。

## 边界与发布状态

- 浏览器使用编译后 Vue 页面和合成 API，不能代替企业 OAuth、模型或真实原生服务的端到端验收。
- 浏览器上传使用合成 PNG；JPEG/WebP 实际解码、跨标签外观刷新及恢复默认 Logo 尚未单独进行浏览器验证。
- 用户尚未提供自有 Logo；实现上传入口并以合成图验证，保留内置 Logo 作为初始回退。
- 图标配额为每用户每空间 100 张、10 MiB，旧图保留以免破坏副本引用；未提供自动清理。Wiki MCP 是有界字面文本搜索与正文读取，不新增生成/重建/写入能力。
- 功能已纳入 2026-10-19 完整包，实际镜像与双来源升级验证见上述包验收；未部署企业服务器。单项验证和包验证均不替代目标环境验收。
- 上游 v0.8.0 子模块保持干净。运行时需要新网关、新前端和产品迁移 000020–000021；无上游源码或数据库补丁。
