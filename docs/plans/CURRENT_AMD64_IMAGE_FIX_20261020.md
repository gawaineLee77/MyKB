## 修复范围

- 接通知识库和问答图片权限校验。当前空间 Owner/Admin 可读取经登记的本空间知识库图片；不能因此读取其他用户的私有会话附件。
- 普通成员依据服务端解析记录确认图片所属知识库，再检查当前可见权限。旧正文中的已登记存储路径转换为不透明资源句柄，不依赖可编辑正文或生命周期附件记录推断归属。
- 提供 `bin/image-resources audit` 只读检查和 `apply --confirm-reviewed` 人工核验流程。产品迁移 `000022` 保存明确确认的关联，不修改上游资源、文档或图片文件。
- 前端快速问答和用户图片使用正确的会话／消息出口；权限变更或窗口重新聚焦时清理图片缓存并重新校验，阻止撤权前的在途请求恢复图片。

带有效多模态解析记录的已登记历史图片可自动恢复。缺少可信关联的已登记图片需运维核验；资源登记或图片文件本身缺失时，本工具不会凭正文链接猜测归属，也不会凭空重建图片。此限制与处理步骤在升级指南中说明。
