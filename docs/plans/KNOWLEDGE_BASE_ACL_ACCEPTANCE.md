# 知识库 ACL 实施与本地验收

日期：2026-10-18。依据[已批准设计](KNOWLEDGE_BASE_ACL_DESIGN_ZH.md)。本记录区分本地代码验证与目标环境上线；不签署企业部署或旧发布包验收。

## 实施范围

- 产品模块 `kbacl`、`kbguard` 和迁移 000018–000019：私有默认、空间公开/指定成员、有效权限、版本冲突、实际操作者审计、创建幂等/恢复和持久撤销。
- 七项内容操作和复合操作；跨 KB 批量对象核验；原文件预览视同下载；独立分块导出；FAQ、Wiki 基本内容与已验证任务进度。
- 以真实调用者校验 Web、问答/Agent、MCP、小助手、历史与图谱；机器 Key 显式 KB 与操作范围；Owner/Admin 当前空间全库管理。
- 单独 Owner 协作执行授权，限定 KB 的内部内容凭据；身份、空间、KB 有序数据库锁；失效后拒绝，不借代理升级调用者权限。
- UI 访问与协作、七项勾选、有效权限按钮、列表筛选、创建恢复、独立执行授权和 API Key 操作范围。

接口写入严格只接受 `revision / visibility / members`；不能把读取策略中的创建者或知识库元数据回传作为授权。`restore-creator` 必须携带当前 `revision`。创建接口要求 `Idempotency-Key`，不确定结果保留操作记录，不自动重复创建。创建前记录完整原生知识库 ID 清单；未完成绑定且不在该清单的新库仅允许管理员盘点/恢复，普通成员和机器不可使用，不依赖跨服务时钟推断归属。

## 收敛与待上线检查

无法证明归属的图片/派生资源、未知任务、跨空间共享、跨 KB copy/move、Wiki 自动修复/重建和 Agent 内部写/SQL/外部工具关闭。原文件按已验证文档归属下载仍可用；资源句柄不能凭可编辑的 Markdown 或 image_info 充当授权证明。完整限制与升级步骤见[使用指南](../guides/KNOWLEDGE_BASE_PERMISSIONS_ZH.md)。

尚未构建或发布新镜像、迁移企业数据、部署或验收真实 OAuth/模型/存储。历史 KB 策略采用可信元数据按需初始化，切换前须完成逐空间盘点、策略初始化及旧 Key 范围确认。不得新旧网关混跑或回退到不检查 ACL 的网关。

`make r5-check` 本轮执行未通过：旧 api-probe/checks/browser/ui-build 指纹及截图复核已过期。历史 R5/AMD64 证据不自动覆盖本次新代码指纹；本记录不宣称当前发布包已通过新的完整发布门禁。上线前仍需生成匹配本次代码的发布包及目标环境证据。
