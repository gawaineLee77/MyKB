# 对话回答导出 Word

更新时间：2026-10-22。主站普通问答和智能体最终回答支持单条导出 `.docx`；需更新前端镜像。没有新增网关接口、服务、配置或数据库迁移。2026-10-22 的带文字箭头修复目前仅在源码中，尚未构建升级包，已交付的 20261020 包不包含此修复。

## 使用方法

1. 打开有权访问的历史对话，或等待本次回答完成。
2. 在回答下方点击下载图标，悬停说明为“导出 Word（可编辑表格和公式）”。
3. 打开下载的 `MindCreek-问题标题.docx`。正文、表格单元格、支持的公式均可编辑。

可用[合成 Word 样例](../assets/word-export/editable-answer.docx)在企业终端验证表格、分式、根式、积分和矩阵的编辑。

Owner、Admin、Contributor、Viewer 都可导出自己当前已显示的回答。没有新的跨空间读取或批量下载权限。导出使用浏览器内已有回答和引用元数据，不调用模型，不新增业务 API 请求，不上传回答到转换服务。

## 内容支持

| 内容 | 导出结果 |
|---|---|
| 标题、段落、粗体、斜体、列表、引用、代码块 | 可编辑的 Word 文本和段落 |
| Markdown 表格 | 原生 Word 表格；可修改内容、行列、宽度和样式；表头重复，单元格自动增高 |
| 简单 HTML 表格 | 标准 Word 表格；原 HTML 样式不保留；嵌套表格、合并单元格和嵌入对象会明确拒绝 |
| 行内、独立及表格内公式 | 原生 Office Math（OMML）；支持分式、上下标、根式、求和、积分、常见装饰符、矩阵及分段表达式 |
| 带标注的单线箭头（2026-10-22 源码增量） | 支持 `\xrightarrow`、`\xleftarrow`、`\xleftrightarrow`，保留上／下标注及其公式结构；仍为可编辑公式 |
| 引用 | 将回答已有的文档标题、分块编号列入参考来源；可匹配的引用标签对应编号 |
| HTTP(S)/邮箱链接 | Word 超链接；应用内部及不安全协议链接保留文字 |
| 图片和截图表格 | 保留图片说明并显示提示；首版不嵌入图片、不识别截图表格 |
| Mermaid | 保留源代码，暂不转换为图形 |

支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 公式标记。代码中的标记保留原文。Markdown 表格公式中的竖线需遵循 Markdown 转义，或使用 `\vert`。

公式先由现有 KaTeX 转为 MathML，再由产品的明确支持结构转换为 OMML。任何不支持的语法或结构会停止本次导出，并提示第几个公式及内容片段；不会以图片代替公式。首版不承诺任意 LaTeX 宏、编号引用、特殊排版命令、图形或任意公式样式的完整兼容。

首版限制：单条回答 200000 字符、300 个公式、单公式 8000 字符；表格最多 16 列、500 个数据行。复杂嵌套和过大公式也会拒绝。正文缺少公式结束标记时应先修正；单独的美元符号按普通文本处理。

## 带文字箭头的 mpadded 报错

旧版导出器不认识 KaTeX 为 `\xrightarrow{\text{标注}}` 生成的 `mpadded` 标签留白节点，因此会提示“第 N 个公式无法导出／暂不支持公式结构 mpadded”。此问题与中文编码、模型配置或知识库权限无关。

2026-10-22 源码修复只接受上述三种单线箭头的标准水平留白结构，转换为 Word 原生伸缩箭头和可编辑标注。任意 `mpadded` 位移、遮盖等特殊排版仍不作无损支持承诺。箭头及标签按 Word 规则排版，不精确复制网页的最小长度和留白；双侧标注中，下标注较长时可超出按上标注伸长的箭头。此修复不表示支持所有箭头命令或任意 `\overset` 组合。

本轮公式结构和浏览器导出回归已通过，主复现公式也已在 Word 中打开并确认显示正确。用户明确本轮无需尝试本机编辑保存，验收以导出正确、界面无报错为准。用于预览的 LibreOffice 对此 Word 原生箭头存在导入兼容问题，详情见[本轮验收记录](../plans/CHAT_WORD_EXPORT_ACCEPTANCE.md#2026-10-22-带标注箭头源码修复)。

合法示例：

```latex
\sigma \xrightarrow{\text{范特西-泽尼克}} \gamma(\Delta x)
\xrightarrow{\text{Gamo矩阵}} \{\lambda\}
```

`\gama` 不是标准命令，应确认原式是否为 `\gamma`；`{lambda}` 表示普通字母，希腊字母是 `\lambda`，显示花括号需写成 `\{\lambda\}`。导出器不自动纠正这些内容，以免改变公式含义。仅修改拼写不能解决旧版本的 `mpadded` 转换缺口，仍需以后更新包含修复的前端。

## 部署与验收

- 使用现有产品前端构建入口。转换模块按需加载，依赖使用上游已锁定的 KaTeX/Marked/JSZip；产品 overlay 显式声明 JSZip 3.10.1，不改上游源码。
- 企业服务器只需更新包含本次代码的前端镜像；不需要 Pandoc、LibreOffice 或 Office 服务端。本轮未构建新的 AMD64 离线包，也未部署企业服务器。
- 浏览器本地导出不会重新请求来源文件；已经显示或下载的内容不提供追溯撤回。
- Word 的受保护视图、编辑权限及字体由企业终端管理。应在实际使用的 Word 版本中完成打开、编辑和保存验证；安装缺失字体会影响排版。
- 整段会话一键导出和员工网页小助手入口不包含在首版中。

代码、验证与兼容边界见[验收记录](../plans/CHAT_WORD_EXPORT_ACCEPTANCE.md)。
