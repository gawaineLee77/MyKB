# 服务外观、智能体图标与 Wiki MCP

适用：2026-10-19 产品层增量；保持 WeKnora v0.8.0 子模块不变。功能已纳入当日 AMD64 完整包，已有 R4 图谱版和 1009 版见[升级指南](UPGRADE_R4_AND_20261009_ZH.md)。实现与验证不表示企业服务器已更新，见[功能验收记录](../plans/SERVICE_APPEARANCE_AND_WIKI_MCP_ACCEPTANCE.md)。

## 全站名称与 Logo

使用安装时配置的本地管理员账号登录，在“设置 → 服务外观”修改服务名称、上传 Logo 并保存。初始名称为“小纳”，支持以后继续改名；配置对所有空间统一生效，与各空间自己的名称无关。

名称支持 1–64 个字符，去除首尾空格，不接受控制字符、不可见格式字符和尖括号。页面提供名称与 Logo 预览。Logo 支持 PNG、JPEG、WebP，源文件不超过 2 MiB，边长不超过 4096 像素且总像素不超过 4194304；保持比例与透明背景，规范化为最大边长 512 像素的 PNG。未上传或选择“恢复默认图标”时使用内置 Logo。

保存后当前页面、其他标签页、重新打开的登录页、浏览器标题与 favicon 使用新配置；其他已打开浏览器在重新获得焦点或刷新时读取最新值。冲突时先重新载入，再决定如何保存。数据库保存配置，重启不丢失。

空间 Owner/Admin、编辑、访客和 API Key 都不能修改全站外观；后端按安装管理员 ID、激活状态和系统管理员资格检查，不依赖前端按钮或角色名称。公共接口只提供名称、Logo 地址和版本，不提供管理员身份、审计或其他配置。更改记录包含实际管理员、请求 ID、名称前后值及图像哈希，不保存原图到日志。

## 知识库来源筛选

知识库内部文档列表的来源选项仅显示：全部来源、本地上传、URL 导入、手动创建、API。飞书、飞书云盘、浏览器扩展及其他来源的现有文档仍通过“全部来源”显示，不删除、不转换这些文档。

## 智能体图片图标

在自定义智能体创建或编辑页面上传图片，可预览、替换、移除；随智能体保存后，在列表、选择器及对话入口显示。未设置或暂时无法读取时使用原有名称图标。权限沿用智能体原生创建和编辑权限，上传格式、大小及规范化规则与 Logo 一致。

图像保存在产品数据库，上游只保存短引用。读取需有效人类会话、空间成员资格和当前智能体可见性；API Key 不用于图标管理。每个用户在每个空间最多存储 100 张、合计 10 MiB，以事务锁避免并发超额。替换或取消编辑留下的旧图不自动删除，以免破坏智能体副本的引用；达到限额时需管理员维护，不可直接删除仍被引用的图像记录。

## Wiki MCP

沿用现有 `/mcp` 地址、认证方式和客户端配置，重新发现工具后可调用：

| 工具 | 参数与用途 |
|---|---|
| `wiki_search` | `query` 必填；可指定 `knowledge_base_ids`；`limit` 默认 10、最多 20。返回知识库、slug、标题、摘要及命中片段 |
| `wiki_read_page` | `knowledge_base_id`、`slug` 必填；`offset` 默认 0；`max_chars` 默认 8000、最多 20000。读取正文，存在 `next_offset` 时可继续读取 |

`wiki_search` 对已生成的 Wiki 内容执行字面文本搜索，跳过未启用 Wiki 的知识库；不负责生成、重建或编辑 Wiki。省略知识库时使用当前凭证可访问的默认范围；显式空数组、null 或无权访问的知识库会拒绝整个调用。无结果返回空列表，不扩大检索范围。多库结果按知识库顺序收集，总数达到上限时提示截断，可缩小知识库范围或细化查询。

适配器单次上游 JSON 响应上限为 1 MiB；超限会报错，不会悄悄截断完整页面。`offset` 按脱敏后正文的 Unicode 字符计数，最大 1000000，必须处于实际正文范围内。

外部智能体通过 API Key 调用时，必须已有 `retrieve` 能力和有效产品知识库范围映射。新增两个工具不会扩大旧 Key 权限。读取前及返回前检查 KB ACL、密钥范围与撤销状态，正文引用验证所属知识库，私有资源链接会被脱敏；读取 Wiki 不授予原文档下载权。沿用 MCP 限流和审计。

```json
{"name":"wiki_search","arguments":{"query":"设备维护","knowledge_base_ids":["your-kb-id"],"limit":5}}
```

```json
{"name":"wiki_read_page","arguments":{"knowledge_base_id":"your-kb-id","slug":"设备维护流程","max_chars":8000}}
```

## 升级与恢复

需要同时更新产品网关与前端，并执行产品迁移 000020（全站品牌及审计）和 000021（智能体图像）。无需上游数据库修改或新的外部存储服务。升级前备份产品数据库，原生智能体的短引用需与产品图片一起恢复。

新表未使用时支持迁移回退再升级；已修改的品牌配置、审计或已保存的图标会阻止破坏性 `down`。应用回退应保留新增表及其数据。旧 UI 无法识别新图标引用，旧网关不提供新增 MCP 工具；不要将旧版本视为完整兼容回退。前序 KB ACL 的授权和回退限制继续适用。
