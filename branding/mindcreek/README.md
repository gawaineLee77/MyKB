# MindCreek Brand Assets

MindCreek represents knowledge that gathers from individual work, forms useful connections, and flows safely through an organization. The mark combines an open knowledge source with a creek-like path. The navy, teal, and green palette is calm enough for an everyday internal tool while remaining distinct from the upstream UI.

## Assets

- `assets/mindcreek-mark.png` is the transparent 1254 px master mark.
- `assets/mindcreek-mark-ui.png` is the optimized 256 px application asset.
- `assets/mindcreek-favicon.png` is the transparent 128 px browser icon.
- `theme.css` contains product-owned color and wordmark styling.
- `brand.json` is the machine-readable identity manifest.

Do not rename technical compatibility identifiers such as `weknora_token`, `WeKnora_theme`, API paths, headers, storage keys, or upstream provider names. The build overlay changes only user-visible product branding.

The mark was generated with the built-in image-generation workflow on 2026-08-25 from this design direction: a minimal, vector-friendly symbol combining a subtle M-shaped creek with knowledge-page contours; deep navy, teal, and fresh green; strong silhouette; no text or third-party marks. Keep the upstream WeKnora MIT license and attribution in every distribution.
